# I18N

English is the default language; Ukrainian is the second language.
Files:

```
data/i18n/en.json
data/i18n/ua.json
```

Both must always have the exact same key structure.

## Adding new text

1. Add the key under `en.json`.
2. Add the same key, translated, under `ua.json`.
3. Reference it in HTML:

```html
<p data-i18n="section.key">Fallback text shown before JS runs</p>
```

For attributes (e.g. `<meta content>`), use:

```html
<meta name="description" content="fallback" data-i18n-attr="content:meta.description">
```

## Rules

- Never hardcode translated text in JavaScript.
- Keep the fallback text in HTML equal to the English value, so the
  page still reads correctly before `app.js` runs or if a fetch fails.
- Ukrainian copy should read naturally — avoid literal word-for-word
  translation, especially for PR/agency terminology (see current
  `ua.json` for tone).
- Language choice persists via `localStorage` (`daaart:lang`) and
  falls back to the browser's language on first visit.
